# ReiserFS development provider

Independent Common V2 read-only source for clean modern-layout ReiserFS 3.5/3.6, using the documented Linux v6.12 on-disk structure definitions, not a VFS proxy. Bounded key-range traversal, allocated-block bitmap checks, packed tails, indirect data, explicit sparse pointers and symbolic links are implemented. Journal replay, old 8 KiB layout, external journals, embedded old directory stat data, writes, defragmentation, packaging, and real-media qualification remain outstanding. The fixture tests and exact-revision CI are authoritative; source presence is not a test pass.
