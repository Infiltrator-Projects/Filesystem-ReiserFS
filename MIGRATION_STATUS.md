# ReiserFS development provider

Independent Common V2 read-only source for clean modern-layout ReiserFS 3.5/3.6, using the documented Linux v6.12 on-disk structure definitions, not a VFS proxy. Bounded key-range traversal, allocated-block bitmap checks, packed tails, indirect data, explicit sparse pointers and symbolic links are implemented. Journal replay, old 8 KiB layout, external journals, embedded old directory stat data, writes, defragmentation, and packaging remain outstanding. Independent real-media root and allocation geometry tests passed for both 3.5 and 3.6 at revision bf7ae4acb53baf8b35652f6c70dae2886a0ad8c5 ([CI 45955903745](https://github.com/Infiltrator-Projects/Filesystem-ReiserFS/actions/runs/45955903745)). File payloads in independently populated media and signed BOOT execution remain outstanding. The fixture tests and exact-revision CI are authoritative; source presence is not a test pass.
